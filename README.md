# Freelancer Dashboard (Vite + React + Tailwind)

## What's included
- Role-based layout (FreelancerLayout) with Navbar and Sidebar components
- FreelancerDashboard page (the UI you provided), placed inside the layout via React Router `<Outlet />`
- Vite build configuration and Tailwind setup files

## Quick start
1. Extract the zip.
2. `cd freelancer_dashboard`
3. Run `npm install`
4. Initialize Tailwind (if you want to rebuild styles) — the config file is already included.
5. Run `npm run dev` to start the dev server.

The project assumes Node.js and npm are installed on your machine.
