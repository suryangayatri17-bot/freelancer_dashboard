# Freelancer Dashboard - UI Only

A clean, role-based freelancer dashboard built with React and Tailwind CSS.

## Quick Start

```bash
npm install
npm run dev
```

Then open: **http://localhost:5173**

## Features

- ✅ Role-based Navbar
- ✅ Sidebar navigation
- ✅ Projects, Proposals, Contracts pages
- ✅ Mock data (no backend required)
- ✅ Responsive UI with Tailwind CSS

## Project Structure

```
src/
├── components/      # Navbar, Sidebar
├── pages/          # Dashboard pages
├── layouts/        # Main layout
├── context/        # Auth context
├── services/       # API/mock services
└── App.jsx         # Main app
```

## Build

```bash
npm run build
```

Production build is in `dist/` folder.
